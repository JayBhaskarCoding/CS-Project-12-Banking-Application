Hey! This is my class 12 half yearly project for computer science.

This is a banking application replica that uses python to connect to a mysql database.

You can create, edit, remove and update customer accounts as well as employee accounts.

To start the application the following prerequisites must be fulfilled:

1). Have Python 3.0+ installed in your system.
2). Have XAMPP (Or any other software that can run MySQL) installed on your system.
3). If you also want to see the database update in real-time then you should enable Apache as well in XAMPP or the software you're using.

Steps to start the application:

1). Turn on XAMPP and on the XAMPP control panel start the MySQL and Apache(If you want to see the database) servers.
2). Once they are up and running. Open the "app_run.bat" file, provided in this zip folder.
3). The program will automatically install any required modules if not present already and then it will automatically create the database and open the application

To use the application:

1). First there are no users so we need to create an employee.
2). Go to employee login and then click add employee and fill the details. The Employer Code Is: "IAMEMPLOYER1234' (#Yeah I Know Its Weird.. But It Is What It Is..)
3). Once employee is created note dpown the EMployee ID displayed.
4). Then login with this ID and your provided password.
5). Then Once you are on the dashboard. Click on create account to add a new customer account.
6). Create a few of the customer accounts and make sure to note down their account numbers.(#If you forget to don't worry just start apache, if not already, and then click on the admin button beside mysql(if on xampp) and then you will be able to see the databse named "Bank_Database")
7). Once satisfied with the no. of customers you can go to the customer login by logging out of employeee dashboard and then login using the customer credentials.
8). There you need to deposit money to start using it for transactions.

Now with money and all you can explore the application.
